# Redesign Website UPT Perpustakaan Politeknik Negeri Jember

Proyek ini merupakan hasil konversi desain UI/UX (*redesign*) halaman beranda **UPT Perpustakaan Politeknik Negeri Jember** dari Figma ke dalam bentuk halaman web statis berbasis HTML, Tailwind CSS, dan JavaScript.

* **Nama:** Zulayka Rivena Br Sembiring Kembaren
* **Program Studi:** Bisnis Digital — Politeknik Negeri Jember
* **Tujuan:** Pemenuhan Tugas Redesign UI/UX Web & Mobile App

## ✨ Fitur & Bagian Halaman
1. **Navbar Navigasi Responsif:** Tautan cepat menuju Katalog OPAC, E-Resources, Layanan, Informasi & Panduan, serta tombol akses SSO Polije.
2. **Hero Section & Pencarian Koleksi:** Kolom pencarian cepat katalog buku/jurnal, tag pencarian populer, dan statistik koleksi perpustakaan.
3. **Fasilitas & Layanan Akademik Unggulan:** Informasi Surat Bebas Pustaka Online, Cek Kemiripan (Turnitin), Database Jurnal Internasional, Self-Service RFID Kiosk, Ruang Diskusi, dan Lab Multimedia.
4. **Koleksi Terpopuler (Interaktif):** Katalog buku pilihan yang dilengkapi tombol filter kategori secara *real-time* (Semua Kategori, Teknologi Pangan, Manajemen Bisnis, Pertanian, Bisnis Digital & TI).
5. **Etalase Riset Terapan (Institutional Repository):** Daftar publikasi tugas akhir, tesis, dan paten terdaftar sivitas akademika Polije.
6. **Agenda Literasi & Jadwal Layanan:** Berita kegiatan literasi terkini serta informasi jam operasional perpustakaan.
7. **Aktivasi Anggota & Footer:** Banner ajakan aktivasi kartu anggota berbasis SSO Polije dan informasi kontak lengkap.

## 🛠️ Teknologi yang Digunakan
* **HTML5** — Struktur semantik halaman web
* **Tailwind CSS (CDN)** — *Styling* tata letak, tipografi, dan desain responsif
* **JavaScript (Vanilla)** — Interaktivitas filter kategori koleksi buku dan simulasi pencarian
* **Figma** — Perancangan *wireframe*, desain antarmuka (*UI*), dan *prototyping*

## 🚀 Cara Menjalankan Proyek
1. Clone atau unduh repositori ini.
2. Buka file `index.html` secara langsung menggunakan browser (Chrome/Edge), atau jalankan melalui server lokal seperti **Laragon** / **VS Code Live Server**.
